## النطاق المنفذ

- واجهة عربية RTL متجاوبة، أربعة أقسام: نظرة اليوم، الالتزامات، القرارات والبيانات، الدليل التقني.
- إضافة وتعديل وحذف الالتزامات والأحداث الثابتة وبداية التخطيط، مع رسائل تحقق عربية.
- محرك جدولة غير قابل للتجزئة يبحث ترتيبات مختلفة؛ لا يستخدم فشل greedy لإثبات التعذر. حد 8 التزامات و32 حدثًا ثابتًا غير متداخل.
- مقارنة خطة البداية الحالية والمؤخرة، وتمييز `already-infeasible` عن `lost-feasibility`. لا نسبة فشل حتمي لالتزام بعينه من تعذر المجموعة.
- جدولان وخطوط زمنية SVG، وخيارات تأجيل بأقل عدد من الالتزامات، حتى ستة أمثلة قابلة للفحص.
- اختيار توقف أو استمرار، وسجل محلي لآخر 100 قرار، واستعادة عند فتح الصفحة وتصدير JSON ومسح مفتاح فسحة فقط.
- مؤقت اختياري يميز الوقت المنقضي عن تفاعل التبويب الظاهر قبل حد خمول دقيقة. لا رصد لمواقع أو تطبيقات أخرى.
- خادم loopback GET/HEAD بقائمة ملفات محددة، وتحقق Host وOrigin ورؤوس CSP وترميز أسماء المستخدم المدخلة.
- بناء مستقل دون حزم تشغيل، وREADME عربي مع ستة Mermaid وثلاثة SVG، وملف معمارية ودليل اختبار فعلي.

## تجربة RED قبل التنفيذ

`node --test` قبل المحرك أظهر 8 اختبارات فاشلة من 8 بسبب الدوال غير المنفذة؛ سجل `red-output.txt`. من بينها توقع `feasible` مقابل `unknown`، وعدم وجود تحقق عربي، وعدم زيادة وقت النشاط، وعدم حفظ القرار. بعد تنفيذ المحرك نجحت الثمانية (`green-core-output.txt`).

للخادم كُتب الاختبار أولًا. أول محاولة واجهت حظر اتصال loopback في sandbox (`EACCES`)، وبعد تشغيل محلي مسموح خارج قيود الشبكة أصبح الفشل المتوقع عدم وجود صفحة فسحة عند الخادم placeholder؛ سجل `red-server-output.txt`. اختبار Host كشف أن fetch في هذا الإصدار لم يمرر Host المخالف؛ تحقق مستقل لخادم يعيد Host أكد أن fetch يرسل المضيف الفعلي، بينما `node:http.request` يمرر المضيف المقصود. استبدلنا وسيلة هذا الطلب فقط بطلب HTTP خام، فأصبح اختبار العزل يقيس سلوك الخادم فعلًا.

اختبار البناء سبق تنفيذه وأظهر أن ملفات الإنتاج غير موجودة في ناتج placeholder (`red-build-output.txt`). بعد التنفيذ يشمل البناء الملفات وصياغة الوحدات والدليل الحقيقي.

## تحقق مرحلة التنفيذ الأولى

البيئة الموثقة Node **v24.19.0** من runtime المجمّع؛ لم يُستخدم global Node. npm CLI المثبت شُغّل بهذا runtime بعد تقديمه في PATH. لا تثبيت dependencies ولا حاجة إلى lockfile لحزم تشغيل.

`npm run verify` يعيد الاختبارات ويولّد الدليل ثم البناء. نتيجة مرحلة التنفيذ الأولى: **10 ناجحة، 0 فاشلة**، مقارنة **200 خطة** مع مرجع مستقل، **8 ملفات إنتاج** بصياغة JavaScript صحيحة. المخرجات الدقيقة أدناه وفي `docs/npm-verify-output.txt`. اختبارات HTTP تستخدم خادمًا مؤقتًا بمنفذ عشوائي على loopback؛ الاختبارات العادية خارج sandbox المشدد لا تحتاج هذا الاستثناء.

## رحلة المتصفح المنفذة

عبر المتصفح الداخلي على `127.0.0.1:4310`:

1. العينة الحالية عند 17:00 وتأخير 15 دقيقة أعطت شاهدين ممكنين، وأقل هامش 25 دقيقة قبل التأخير و5 دقائق بعده.
2. اختيار 30 دقيقة أعطى شاهدًا حاليًا ممكنًا وتعذرًا بعد التأخير، وخيار تأجيل «مراجعة درس».
3. تعديل مدة المراجعة إلى 95 دقيقة أعطى «الخطة متعذرة أصلًا» قبل التأخير أيضًا، دون نسبته للدقائق الإضافية.
4. تحميل العينة وإضافة التزام مؤلف ثم حذفه نجح؛ رفض حفظ حدث مؤلف 18:10–18:30 لتداخله مع حدث 18:00–18:20 برسالة عربية.
5. اختيار استمرار ثم توقف سجّل القرارين؛ إعادة تحميل صفحة السجل استعادتهما، والمؤقت بقي متوقفًا.
6. فحص بصري على viewport 390×844: تخطيط الهاتف متجاوب، وعرض المحتوى الفعلي 375 يساوي scrollWidth 375، دون تجاوز أفقي. أعيد viewport الافتراضي بعد الفحص.

التصدير مطبق باستخدام JSON Blob وتنزيل المتصفح؛ لم يُنزّل ملف فعلي في جلسة التنفيذ حفاظًا على نطاق الملفات الخاص بهذا المنفذ. صور الواجهة النهائية وفحص التصدير والتنظيف الشامل للعرض يتولاها المنسق لاحقًا؛ لا تُقدّم مخططات SVG بوصفها screenshots.

## قرارات وحدود

- الخطة من يوم واحد فقط؛ الإدخال خارج اليوم أو أكثر من ثمانية التزامات يرفض صراحة.
- البحث يعطي شاهد إمكان كاملًا ضمن النموذج المحدد، ولا يحسن الأولويات أو أفضل هامش. كل ادعاء نتيجة مشروط بالمدخلات والمدة المقدرة.
- مجموعة التعارض هي الالتزامات المتعذرة معًا، وليست نواة تعارض دنيا؛ خيارات الإزالة هي أمثلة بأقل عدد، وليست كل البدائل الممكنة.
- clear يمس `fusha.v1` فقط؛ نموذج العينة بعده لا يحفظ حتى تعديل أو قرار. reset للعينة يبقي السجل.
- الخادم محلي ثابت، ولا توجد أدوار أو صلاحيات مستخدمين متعددة أو مشاركة خارجية. API live status: **لا تكامل API خارجي، ولا مفتاح Gemini، ولا تجربة اتصال AI حي**.
- لا مستخدمون حقيقيون أو نتائج ميدانية أو تحسن علاجي مثبت. العينة والقرارات المستخدمة للتحقق مؤلفة. الحقوق محفوظة دون اختراع رخصة مفتوحة.
- صلة Motion وRescueTime موثقة بمصادر رسمية؛ لا ادعاء بأن الميزة غير موجودة لديهما أو أنها جديدة عالميًا.
